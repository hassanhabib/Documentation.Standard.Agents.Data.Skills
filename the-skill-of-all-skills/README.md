# The SKILL of All SKILLs

This is the constitution for consuming skills: the one skill that tells an agent, and its
Gate, Brain, and Judge, how to consume every other skill. It is the loadable form of
Chapter 1, written as a skill per Chapter 0, and it is the flagship test of this Standard.
If the Standard could not express it, the Standard would be wrong.

It is not ordinary content. It is loaded unconditionally at the agent's birth, outside the
loop, from a trusted root. It is never filtered by the Gate and never questioned by the
Judge, because it defines them. It sits above the priority ladder, and it is subordinate to
exactly one thing: the ethical constitution (see `0.1`), which outranks it. It is immutable
and signed, and it is never amended from inside the loop. A change to it is an out-of-band,
human act.

The loadable skill is [SKILL.md](./SKILL.md), and it is the only thing an agent should be
pointed at. This README is human context; that file is the constitution.
